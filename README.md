## Features

- **Encrypted local database** your financial data never leaves your device unprotected
- **Income, expense & transfer tracking** full control over every transaction
- **Custom categories** organize spending with your own colors and icons
- **Spending limits & monthly snapshots** stay on top of your budget at a glance
- **Recurring transactions** automate salary, bills, and subscriptions
- **Financial goals** set targets and track progress over time
- **Biometric unlock & encrypted backups** security without the friction
- **Multi-language support** available in Vietnamese and English ( will support more )

## Philosophy
Your money, your data, your privacy. No ads, no tracking. I don't care about your data. All I care about is your experience. <br/>

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### Installation

```bash
git clone https://github.com/nupniichan/nuvora.git
cd nuvora
npm install
```

### Running the App

Start the Expo dev server:

```bash
npm run start
```

Then choose your target platform:

| Platform | Command | Notes |
|----------|---------|-------|
| Android | `npm run android` | Requires Android Studio or a real device |
| iOS | `npm run ios` | Requires Xcode (macOS only) |
| Web | `npm run web` | Runs in browser via `react-native-web` |

> **Important:** This app uses SQLCipher for database encryption, which requires a **development build**. Expo Go is **not supported** — you must create a dev client:
>
> ```bash
> npx expo run:android   # Android dev build
> npx expo run:ios       # iOS dev build
> ```
